SYSTEM REQUIREMENTS

1) Microsoft Windows 95/98/NT/2000/XP.

DIRECTORY CONTENTS

Directory root - SDK DLL's.

Doc - Programmer's manual.

Include - include files (*.h).

Lib - libraryes (*.lib). 

Bin - the LSHead program itself.

Samples - SDK samples 'LSH_SDK_EXAMPLE.exe' and 'SpeedTest.exe'. See 'SDK_Example_Readme.txt' 
          and 'SpeedTest_Readme.txt'for details.
